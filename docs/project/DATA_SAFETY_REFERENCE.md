# Google Play Data Safety Declaration Reference

Use this document to fill out the Data Safety form in the Google Play Console for **InterviPrep**.

## 📊 Data Collection & Security

| Category | Data Type | Purpose | Optional? |
| :--- | :--- | :--- | :--- |
| **Personal Info** | Name | Account management, app functionality | No |
| **Personal Info** | Email address | Account management, communications | No |
| **Audio Files** | Voice recordings | App functionality (Voice interviews) | No |
| **Identifiers** | User ID | Account management, analytics | No |
| **Identifiers** | Device ID | Analytics, security, fraud prevention | No |

## 🔒 Data Practices

*   **Data Encryption**: All data is encrypted in transit using HTTPS/TLS.
*   **Data Deletion**: Users can request data deletion via support or by deleting their account.
*   **Data Sharing**: We do not sell personal data. Data is shared with service providers (Supabase, Firebase, OpenAI) strictly for app functionality.

## 📝 Detailed Declarations

### 1. Audio Recording
*   **Collected**: Yes
*   **Processed Ephemerally**: No (Stored for interview playback and AI analysis)
*   **Purpose**: App functionality (Interview practice)

### 2. User Identifiers
*   **Collected**: Yes (User ID)
*   **Purpose**: Account management, Analytics

### 3. Contact Info
*   **Collected**: Yes (Email, Name)
*   **Purpose**: Account management, Communications

### 4. Device Identifiers
*   **Collected**: Yes (Instance ID)
*   **Purpose**: Analytics, Fraud prevention
